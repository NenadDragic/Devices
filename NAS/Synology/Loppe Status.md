# Loppe Status

Prints the contents of the Loppe status file to the terminal.

> **Replaced by [`Hent - Loppe.sh`](Hent%20-%20Loppe.md)**, which fetches the Loppe files and prints `status.txt` in the same job.

## Command

```bash
cat /volume1/Dragic/Rap/Loppe/status.txt
```

## Usage

```bash
bash "Loppe Status.sh"
```
